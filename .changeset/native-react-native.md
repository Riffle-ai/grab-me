React Native support: `GrabMe` from `@riffle-ai/grab-me/native` adds a tap-to-grab picker to a development build (armed from the dev menu, a hotkey or the CLI), and the new `grab-me` command reads a running app through Metro's debugger connection: `screen` lists what is on screen with where each piece is written, `at`, `pick`, `arm` and `last` grab elements, and `raycast` writes a Raycast script command so a hotkey arms the picker.
